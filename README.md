# Словник неправильних дієслів (Rust + egui)

189 неправильних дієслів, миттєвий пошук (англійською та українською), підсвічування збігів, світла/темна тема.
Словник і іконка вбудовані прямо в .exe на етапі компіляції — програма нічого не читає з диска під час роботи,
тому копіювати "по частинах" нічого: є лише один exe-файл.

## Варіант A: зібрати через GitHub (без встановлення нічого)
Завантажте цю папку як репозиторій на GitHub → вкладка **Actions** сама збере:
- `irregular-verbs-exe` — сам застосунок (один файл)
- `irregular-verbs-setup` — Windows-встановлювач (Setup.exe)

## Варіант B: зібрати локально на Windows
1. Встановіть Rust: https://rustup.rs
2. Встановіть Inno Setup (безкоштовно): https://jrsoftware.org/isdl.php
3. Запустіть `build.bat` — він збере `irregular-verbs.exe`, а потім встановлювач
   `installer_output\irregular-verbs-setup.exe`.

Якщо Inno Setup не встановлено, `build.bat` все одно збере робочий `irregular-verbs.exe`,
просто без інсталятора.

## Що робить встановлювач
- Ставить програму в `Program Files` (без прав адміністратора — `PrivilegesRequired=lowest`)
- Створює ярлик у меню «Пуск» і (за бажанням) на робочому столі
- Додає деінсталятор
- У дистрибутив потрапляє лише скомпільований `.exe` — папки `src/`, `data/`, `assets/`
  в інсталятор не включені (дивись секцію `[Files]` в `installer.iss`)

## Додати слова
Відредагуйте `data/verbs.txt` (формат `infinitive|past|participle|переклад`) і перезберіть проєкт —
слова вшиваються в exe при компіляції.
